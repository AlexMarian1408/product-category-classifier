# Product Category Classifier

Proiect Machine Learning pentru clasificarea automată a produselor în categorii pe baza titlului produsului.

## Obiectiv
Antrenarea și evaluarea mai multor modele de Machine Learning pentru prezicerea categoriei unui produs.

## Dataset
Dataset utilizat: `products.csv`

## Tehnologii
- Python
- Pandas
- Scikit-learn
- Jupyter / Google Colab
- GitHub
